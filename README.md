#  Hospitality Dashboard – Power BI Project

This Power BI report provides an interactive overview of key performance indicators in the hospitality industry. It is designed to help hotel managers and stakeholders gain insights into occupancy trends, revenue performance, guest demographics, and seasonal patterns.

---

##  Features & Visuals

The dashboard includes the following insights:

- **Occupancy Rate Analysis**
  - Daily, weekly, and monthly trends
  - Room type distribution
- **Revenue KPIs**
  - Average Daily Rate (ADR)
  - Revenue per Available Room (RevPAR)
  - Total revenue by room and service type
- **Booking Channel Insights**
  - Direct vs. third-party bookings
  - Cancellation trends
- **Customer Demographics**
  - Geographic distribution
  - Guest type segmentation (business, leisure, etc.)
- **Seasonality Trends**
  - Monthly performance comparison
  - High/low seasons and forecasted trends
